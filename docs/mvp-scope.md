# MVP 范围

首阶段交付可继续开发的本地基础，不把空壳或文档声明当作上线完成。

## 本轮交付

- 初始化独立 Git 仓库、项目文档和分阶段计划。
- 最小 React 页面：资源目录、状态选择、历史区与空态说明。
- JSON Schema 与语义校验：来源、时间、状态、重复标识、历史记录。
- 正式数据为空；测试中仅使用明确标注的合成数据，不导入站点。
- Resource Research Skill 和未启用的调度提示词。
- GitHub Actions 检查与 Pages 发布配置；发布需仓库变量显式启用。
- 记录可行的本地检查、账户探测和外部能力阻碍。

## 后续阶段

先完成云端能力门槛验证，再选择少量真实官方活动开展人工对照采集，
最后验证 Skill 驱动单次运行的更新与发布链路（不做定时调度）。失败不自动切换到付费 API 或自建云服务器。

## 不属于本轮验收

真实福利覆盖率、生产调度持续稳定性、所有地区领取可用性、Pages 已上线。
不增加用户交互型业务；状态选择只是本地只读浏览。
