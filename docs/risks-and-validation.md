## 官方说明与账户事实的边界

[Scheduled tasks](https://learn.chatgpt.com/docs/automations?surface=app)
说明本地任务依赖电脑和应用运行，Web 任务可使用连接工具但没有持久本地工作目录。
[设置定时任务](https://developers.openai.com/training/walkthroughs/scheduled-tasks)
建议先手动跑通提示词，再调度；Cloud 选项受可用性影响。
这不证明当前账户已具备可写远端 Git 的云端定时链路。
当前普通 Codex 用量受账户额度限制，不宣称零消耗，不自动购入额度。

## 云端能力验收步骤

1. 在用户已登录的云端入口确认 Scheduled 和执行位置确实可选 Cloud。
2. 授权一个专用远端测试仓库或分支，明确只可写一份 probe JSON。
3. 手动云端读取仓库及 Skill，记录源提交 SHA、网络访问结果和校验输出。
4. 执行一次受限写入，远端重新读取同一内容并记录提交 SHA；权限元数据不算通过。
5. 创建一次性云端定时测试，关闭本地应用或使用独立运行证据证明不依赖本机。
6. 核对预定时间、实际启动、执行位置、提交、失败重试、是否弹出人工批准及用量变化。
7. 第二次无变化运行不产生提交；并发变更必须拒绝覆盖，最多重新读取重算一次。
8. 验收后关闭测试任务，再确定正式频率和目标分支；不默默留下测试调度。

本轮先把本地工作做完。完整远端测试需要登录入口和明确写入授权，
不能以用户“实测”的要求绕过同一请求中的“不自动推送”。

## 内容风险

官方网页可能撤回或改版；保存简短摘要与获取时间，不整页复制。
抓取失败是复核失败，不代表资源失效；历史可信数据保留并提示待复核。
时间过期可由日期推导，资格和额度必须来自官方资料。
Schema 只能校验结构，不能自动证明域名属于官方或内容真实。
地区、信用卡、自动扣费不明时明确标为未知。
