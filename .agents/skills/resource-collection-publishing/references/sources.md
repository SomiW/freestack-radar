## 重点回访厂商

- 华为云：地区/实名或企业认证/新用户范围、实例 CPU/RAM/磁盘、镜像区域、代金券抵扣及续费定价。
- InstaBox：确认准确厂商主体与官方活动页；免费实例数量、配置、存储期限、账号限制与重新开放公告。
- LightVela：确认准确厂商主体与官方入口；产品所在区域、实例配置、限时/长期、是否涉及付款/隐藏条件。
- CodeBuddy：官方套餐与地区、新用户条件、AI 调用额度/模型范围、活动截止与续费。
- Muse：先消歧具体品牌或产品，只有明确官方主体才创建福利条目；核对额度、适用范围及到期规则。

**触发复核条件**：出现“重新开放/补货/续期/活动重启/额度上调或缩水/地区变化/计费变更”，或 `nextReviewAt` 到期。没有新帖子也要按计划复核官方页面；某论坛消息沉寂不等于活动失效。

## 信息来源等级

1. **官方证据**：厂商可归属官网、官方条款/价格/API 文档、有效的官方公告。用于核实是否可发布及核定可信度。
2. **官方关联但不完整**：官方社媒/论坛管理员公告，需核对关联身份与正式条款；未证实资格/费用时不能视为 high。
3. **社区/聚合线索**：上述论坛、福利聚合站、第三方文章。用于发现，默认低可信，不能直接标 active。

## 候选信息字段与审查流程

发现队列至少包含 `sourceName`、`discoveryUrl`、`discoveredAt`、`rawTitle`、`providerCandidate`、`officialUrlCandidate`、`category`、`fingerprint`。队列不直接供前端消费。

1. 去重：相同官方活动 URL 优先；备用网址规范化时不要误合并不同活动批次。
2. 官方：先访问普通官网入口，失败才尝试**已授权且可用**的 Firecrawl；不得自动绕过风控或登录。
3. 逐项抽取：权益/价值、资格、地区、时效、真实配置、信用卡与费用，以及核实证据。
4. 标级：缺乏官方证据或关键费用/资格信息时放入待审队列，不自动写成 active。
5. 每次发现新数据、变更或失效时留下摘要和官方 URL；未变化不产生提交。

## 发布与频率

首次试运行推荐手动 `workflow_dispatch` + dry-run；验证成功后再设计 `schedule`。按来源服务条款限速，默认单次最多发现 3 条/复核 5 条，重要活动可配置高优先级。常规复核最长 7 天，结束日期临近时提高优先级。通过核实且写入 main 后，现有 Pages 工作流负责自动构建发布；PR 仅创建不会直接发布生产站点。

**当前状态**：这份文件仅定义来源和审查方法。真实源站 API/RSS、定时采集脚本与无人值守官方校验尚未实现或验证。
