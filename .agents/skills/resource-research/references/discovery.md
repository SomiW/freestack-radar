# 来源发现、官方核实与交接

本规则配合 `sources.json` 按需执行，不实现采集程序或定时 workflow。
来源更新与福利核实是不同操作；读取一个目录成功不能刷新活动的 lastVerifiedAt。

## 来源登记与维护

每个来源独立登记名称、URL、topics、P0/P1、kind、methods、entryUrl、
checkedAt、lastSuccessAt、lastFailure、status、observation 和 canVerifyOfficial。
这些字段仅存在于 Skill 参考配置，不扩展正式资源 Schema。

- kind：official / aggregator / community / price-reference。官方合作权益目录
  只能证明它自己公布的条款，合作商家的价格、资格与续费需继续读取该商家官网。
- status：readable 表示本次得到列表/摘要/结构化内容；restricted 表示风控、
  登录、证书或动态内容限制；unavailable 表示当前入口如 404；unverified 表示尚未验证。
  来源状态不能映射成福利状态。
- lastSuccessAt 只记录实际得到内容的时间；仅 HTTP 200 外壳/访问确认不算成功。
  本轮失败保留历史成功时间，更新 checkedAt 和 lastFailure；成功后仍保留最近失败
  以供排障，不能用失败刷新活动 evidence 或 lastVerifiedAt。
- observation 记录方法、内容类型、列表范围和可见更新信号；无明确日期写未知。
  RSS pubDate、GitHub pushed_at、页面生成日、站方核实日均不等于官方活动发布时间。
- 优先公开 API/JSON、RSS/Atom、GitHub README/元数据，最后使用允许匿名读取的 HTML。
  新发现端点先验证再登记；不根据站点框架猜测 API 或遍历私有接口。
- HTML 只有外壳时，先检查页面明确引用的公开 JSON、RSS 和数据脚本链接；
  无结构化入口时可用正常匿名浏览器渲染并读取可见列表，不注入验证凭证或改变指纹。
  本项目已实测的具体方法见 [受限来源读取方案](access-paths.md)。
  不在本机执行下载的第三方脚本；站内数据的声明数量、自动模板与换算金额均需独立核对。
- 网页工具仅因不支持 RSS/Atom 的 XML 内容类型而失败时，不要标源站受限；
  可用普通匿名 HTTP 客户端（如 curl）读取原始 XML 并解析。只有实际源站响应才用于
  判断 403/429。不修改客户端指纹、复制登录 Cookie 或使用代理绕过实际拒绝。
- 请求前检查当前服务条款、robots 与限速要求。先用已实测 RSS，正文按需读取；
  只读渲染代理仅补充公开正文，不用于绕过防护。403/429/验证码/登录要求出现即停止
  本来源本轮请求、记录失败，继续其他独立来源。TLS 错误不能关闭证书校验。
  仅正常访问完全不可用且已有授权时尝试 Firecrawl，不启用付费资源。
- 列表读取窗口与本轮新增入库上限分开：研究 Skill 默认最多新增 3 条，不等于每源只读
  前 3 条。优先一次结构化请求筛选普通开发者可领取的相关类别和最新变化；例如 Perq
  登记的 anyone + category + newest + limit=20。先筛选和去重，再取最多 3 条入库。
- 默认每源一次列表请求、不无限分页；新内容按已见链接与实际条款变化增量判断。
  重复抓到旧帖子、回帖置顶或聚合站重新生成页面不算新活动。

## 范围与分类

发现队列使用六种 topics：ai-api、ai-coding、developer-tools、gpu、vps、
developer-benefits；这不是正式资源 category 枚举。

覆盖模型 Token/API/试用赠金，Codex、Claude Code、Cursor、Copilot、Gemini CLI
等编程工具，IDE/数据库/CI/CD/SaaS/域名/托管，GPU 训练推理与算力券，免费或低价
VPS/云服务器，以及学生、创业、开源开发者计划。保留云电脑及 AI Agent 沙箱范围。
优先普通开发者实际可领取的权益；明确有学生/企业/邀请资格的活动不冒充普惠。

正式数据沿用 ai / cloud / both：模型及 AI 工具用 ai，云、算力与基础设施开发服务
用 cloud，实质同时覆盖二者才用 both。普通软件权益若无法如实映射当前产品范围，
先留研究报告，不强行归类或新增枚举。过滤无关购物、抽奖、邀请码刷量、身份伪造、
支付地区绕行、密钥转卖、恶意下载及不可确认价值的宣传。

## 从发现到官方核实

顺序为发现 → 找官方来源 → 核权益 → 核限制 → 判断状态 → 去重 → 入库。
发现时先做轻量重复预筛；最终去重在确认条款和活动轮次后进行。

1. 在本轮研究报告保存 sourceName、discoveryUrl、discoveredAt、rawTitle、
   providerCandidate、officialUrlCandidate、topics、fingerprint 和其他转载发现链接。
   未找到可归属官方入口时留研究队列，不把聚合站填成 officialUrl/claimUrl。
2. 正常打开官方活动、产品、定价与条款页，确认域名归属及跳转终点。
   不执行购买、领取、注册、登录、支付或请求秘钥；不访问计数/投票/订阅写接口。
   Perq 等聚合站的 source_url 可定位官网，但其 last_verified 不可复制成本项目核实时间。
3. 逐项核对权益、资格、新老用户、信用卡、学生身份、邀请码/企业条件、地区限制、
   开始/截止与个人额度有效期、领取步骤、自动续费、超额费用。官方未披露填未知，
   不以 null 截止日认定永久有效。不得把第三方网关宣传当成模型原厂承诺。
4. 价格保留原币种（CNY/USD/EUR 等）、原金额及计费周期，不依赖参考站汇率排序。
   在 quota / benefitValue / costNotes 中记活动价、原价、首期与续费、优惠码适用范围
   和是否循环折扣；未知续费明确写未知。VPS/GPU 补充 CPU/RAM/磁盘、GPU 型号/时长、
   地区、带宽/流量/FUP、IPv4、税费、设置费、押金、预授权及额外网络/存储费用。
   云电脑/Agent 沙箱保留隔离方式、单次时长、休眠/回收、并发、持久存储和额外运行费用；
   AI Coding 记录功能、模型与调用限制，API 记录速率与额度有效期。
   无法可靠换算价值时直接披露，不编造金额或优惠幅度。
5. 当前官方证据确认开放且关键条件清楚才 high + active；有官方佐证但条件缺项
   为 medium + pending；仅第三方、冲突或官网不可达为 low + pending。
   有真实来源且当前 Schema 必填字段可如实填写的 pending 草案可公开，不能公开为有效。
6. 官方证实未开始且开始时间已知用 upcoming；明确截止已过用 expired；确认撤销或
   停止用 unavailable。失败保留上次可信记录，不能用网络失败判终止。
   每次活动研究运行按主 Skill 扫描所有有效活动的 24 小时复核队列，报告未处理积压。

## 跨来源去重与内部排序

优先核对官方 URL，其次提供方 + 活动名、权益/条件、时间窗口。
去除 fragment、统一尾斜线；仅在确认不会改变活动身份时去掉 utm 等追踪参数。
保留优惠码、plan、region、轮次等可能改变权益的参数；官方域名相同不代表活动相同。
低置信的相似候选先人工/Agent 对照条款，不按标题相似度自动合并。

同一优惠由多个聚合站转载时保留既有 id 和主 discoveryUrl，在研究报告合并其他发现
链接；正式 Schema 只有一个 discoveryUrl，不新增 sources 字段，不把转载放进官方 evidence。
新的活动轮次需新 id；同一官方页复用但窗口不同先复核当前记录与历史，再决定本轮更新，
不得绕过现有重复官方入口校验。校验器拒绝重复是兜底，合并由研究环节完成。

内部候选可按 0–5 分分别评估价值、可信度、时效、可领取性，
总分 = 价值×0.30 + 可信度×0.30 + 时效×0.20 + 可领取性×0.20。
每项在报告说明证据，缺项写未知并保守计 0；价值考虑净成本与周期，不能只比较赠金面额。
先过官方核实门槛再排序；高分不改变 pending 状态，也不写入资源 Schema 或前端排序。
优先复核有截止边界、发生实质变化且普通开发者可领取的候选；不按转载次数加分。

## 校验与交接

来源登记由 `schema/sources.schema.json` 及 `scripts/source-registry.ts` 检查；
现有 `npm run validate:data` / build / check 同时覆盖登记格式与语义，不发网络请求。
来源失败是允许的研究结果，不因来源受限阻断其他来源或已有站点构建。

交给发布 Skill 的内容包括去重结果、正式字段建议、实际官方证据/时间、价格风险、
来源失败与复核积压。发布 Skill 不补做网络采集或虚构官方结论。
任务明确未授权推送时，只提供本地差异和校验结果，不因历史草案直发权限推送。
